# Wawan — Portfolio Website

Personal portfolio website built with React + Vite.

🌐 **Live:** https://wan-projects.github.io/Web-Portofolio-Wawan/

## Tech Stack

- React 19 + Vite
- Pure CSS (no CSS-in-JS)
- react-icons
- Deployed via GitHub Actions → GitHub Pages

## Run Locally

```bash
npm install
npm run dev
```
